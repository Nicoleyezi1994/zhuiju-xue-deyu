# 追剧学德语

*追剧学德语——用你已经在追的剧，学会一门语言。*

**面向 B1 及以上水平的德语学习者。** 这个工具的设计前提是你已经掌握基础语法和常用词汇，需要的是"沉浸在真实语速的内容里，突破到中高级"，而不是零基础入门——生词/语法点的选取标准也是按这个水平定的（跳过初学者早就学过的基础词，同时避开过于生僻的专业术语）。如果你还在 A1/A2 阶段，更适合先用别的教材打好基础再回来用这个工具。

一个单文件、免搭建、完全在浏览器里运行的字幕学习播放器，让你通过追一部自己感兴趣的德语（或其他任何语言）剧集来学语言。它会把双语字幕跟你本地的视频文件同步播放，把值得学的生词高亮出来（点一下就能看到释义、例句、语法笔记），提供德语发音朗读，还能为每一集自动生成剧情总结、关键片段回放列表和练习题——所有这些内容都来自一个你自己（或者请 AI 助手帮你）为每一集准备的小型 JSON 数据文件。

**这个仓库本身只包含播放器引擎代码。** 不含任何有版权的字幕原文、翻译或视频。你需要自备本地视频文件（完全在你浏览器本地播放，不会被上传到任何地方）以及自己准备的标注数据文件，数据来源应该是你本来就有权使用的字幕。

## 功能

- 双语字幕实时同步显示，视频完全在本地播放（通过浏览器的 File API 直接从磁盘读取，不会上传到任何服务器）
- 点击任意高亮的生词，查看释义、例句和语法笔记
- 可选"遇到标注过的生词时自动暂停"，给自己留出阅读时间
- 暂停时显示整句的中文翻译，哪怕这句话里没有标注过的生词也一样
- 本地文本转语音（Web Speech API）朗读任意德语文本——不联网、不需要 API key
- 每一集都有剧情总结（简介、核心句型、完整生词表、语法点）
- "关键片段"回放列表——一键跳转到指定时间点
- 自动判分的练习题（选择题 + 填空题），进度保存在浏览器 `localStorage` 里
- 支持多集：一个按季分组的剧集下拉选择框；新增一集只需要加一个数据文件+manifest里的一行，完全不用改代码
- 自动记忆播放进度：每隔几秒和暂停时都会记录当前播放位置（按集分别记录），下次选择同一集的视频文件时会自动跳回上次看到的地方
- 全屏按钮会把字幕一起带入全屏（浏览器原生的全屏按钮只会让 `<video>` 元素本身全屏，字幕层会被落在外面）

## 快速上手

1. Clone 这个仓库。
2. 把 `manifest.example.js` 复制一份改名为 `manifest.js`。
3. 准备好你自己的剧集数据文件（格式见下面的"数据结构"部分），放进 `data/` 文件夹。
4. 在 `manifest.js` 里给这一集加一行。
5. 直接用浏览器打开 `index.html`（双击就行，不需要起服务器），或者用任意静态文件服务器托管这个文件夹。
6. 点击「选择本地视频文件」，选取你自己电脑上对应的视频。

（如果你还没做第 2-4 步就直接打开 `index.html`，会自动显示随附的示例数据，页面顶部会有提示条告诉你这一点，方便你先感受一下播放器长什么样。）

## 处理视频文件

浏览器的 `<video>` 元素只能解码 AAC 或 Opus 格式的音频。很多下载/压制的视频文件（尤其是标了 DD+/Atmos/AC3/DTS/EAC3 音轨的）画面完好，但音频编码浏览器解不了，播放时就会有画面没声音。用 `ffmpeg` 一次性修好（只重新编码音频，视频流直接拷贝，所以速度快、画质无损）：

```bash
ffmpeg -i input.mkv -map 0:v:0 -map 0:a:0 -sn -c:v copy -c:a aac -ac 2 -b:a 192k -movflags +faststart output.mp4
```

这条命令在 macOS / Windows / Linux 上写法完全一样，只是先要装好 `ffmpeg`：macOS 用 `brew install ffmpeg`；Windows 用 `winget install ffmpeg`（或去 [ffmpeg.org](https://ffmpeg.org/download.html) 下载，解压后把 `bin` 目录加进系统 PATH）；Linux 一般 `apt install ffmpeg` / `dnf install ffmpeg` 之类。装好后在终端（Windows 上是 PowerShell 或 CMD）里运行上面这条命令即可。

## 数据结构

每一集是一个 JS 文件，设置 `window.APP_DATA = { cues, vocab, grammar, summary, keyScenes, quiz }`。完整带注释、可直接运行的示例见 [`data/example-episode.js`](data/example-episode.js)，每个字段都有说明。简单来说：

- **cues**：每条字幕对应一条——毫秒级时间戳、德语原文、译文，以及是否是纯音效（非台词）提示。
- **vocab**：标注的生词/短语，含释义、例句和可选的补充说明；每条还列出了高亮引擎应该在字幕正文里匹配的具体词形。
- **grammar**：简短的语法讲解，锚定在某一条具体字幕上，学习者暂停到那附近时会显示出来。
- **summary**：剧情简介 + 一小份核心句型列表，显示在"总结"这个标签页里。
- **keyScenes**：值得回放的时间段列表。
- **quiz**：选择题或填空题，含答案和解析。

### 生成你自己的数据文件

这些 JSON 不需要你手写。如果你已经有这一集的 `.srt` 字幕文件，AI 编程助手（比如 Claude）可以帮你：

1. 把 `.srt` 解析成一条条 cue（一个最基础的起点脚本在 [`tools/parse_srt.py`](tools/parse_srt.py)）
2. 通读一遍台词，挑出超出初学者水平的生词，写好释义/例句/补充说明
3. 逐句翻译
4. 挑几个语法点、几段关键场景，出几道练习题
5. 把这些内容按照上面的数据结构，整理成一个 `data/<你的剧集ID>.js` 文件

示例数据文件（以及这个项目最初围绕的那部真实剧集的私人数据）正是这么做出来的——这个仓库只是不会把那些由字幕衍生出来、带版权的具体内容一起发布出来。

**想让 AI 助手第一次就做得更好**，把 [`GENERATING_EPISODE_DATA.md`](GENERATING_EPISODE_DATA.md) 也一起交给它——里面详细展开了上面这五步该怎么做，以及几个容易踩的坑（翻译错位怎么发现、生词难度怎么校准、填空题提示怎么给才够、以及两个用来自动核对质量的脚本：跨集查重用的 [`tools/check_dup.py`](tools/check_dup.py) 和生词高亮校验用的 [`tools/check_highlight.py`](tools/check_highlight.py)）。这些都是做这个项目自己那部剧的私人数据时，一轮一轮改出来的经验，不看这份文档的话，第一版大概率能跑起来，但要达到这个质量还得自己来回纠正好几轮。

如果你用的是 Claude Code，这个仓库还自带了一个对应的 Skill（[`.claude/skills/bingelingo-episode-data/`](.claude/skills/bingelingo-episode-data/SKILL.md)），内容跟 `GENERATING_EPISODE_DATA.md` 一致，克隆下来后会在你说"做新一集数据"之类的话时自动生效，不需要手动把文档粘贴给它。

## 多集设置

`manifest.js` 是决定下拉框里显示哪些剧集的唯一依据：

```js
window.SERIES_MANIFEST = [
  { id: "s01e01", season: 1, episode: 1, title: "S01E01 · ...", file: "data/s01e01.js" },
  { id: "s01e02", season: 1, episode: 2, title: "S01E02 · ...", file: "data/s01e02.js" },
];
```

新增一集完全不需要碰 `index.html`——只要加数据文件、在这里加一行就行。每一集的学习进度/练习题记录都是按 `id` 独立存储在 `localStorage` 里的，切换剧集不会互相干扰。

## 浏览器存储与隐私

- "已掌握"标记和练习题作答记录都保存在你浏览器的 `localStorage` 里，按剧集 `id` 分开存放。不会发送到任何服务器——因为压根没有服务器。
- 文本转语音用的是浏览器自带的 `speechSynthesis` API。语音质量/可用性取决于你的操作系统和浏览器自带了哪些语音；如果发音按钮点了没声音/只有英语，说明系统里还没装德语语音包，需要手动加一个：macOS 上去"系统设置 → 辅助功能 → 朗读内容"添加德语语音；Windows 10/11 上去"设置 → 时间和语言 → 语音"，在"管理语音"里添加德语语音（或者去"时间和语言 → 语言和区域"里添加德语这门语言，通常会连带装好对应的语音包）。添加完之后需要重新打开浏览器标签页，新语音才会被 `speechSynthesis` 识别到。
- 视频文件永远不会离开你的电脑：是通过 `URL.createObjectURL()` 读取浏览器本来就能访问的本地 `File` 对象来播放的。
